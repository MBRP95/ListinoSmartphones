DEVICE PROPOSER - PUBBLICAZIONE GITHUB PAGES

Carica questi elementi nella root del repository:
- index.html
- devices.json
- stock.json
- cartella images/

Non rinominare index.html.
Configura GitHub Pages per pubblicare la root del branch scelto.

Per aggiornare i dati:
1. Apri il sito, entra in Store e modifica le schede.
2. Esporta il pacchetto ZIP dall'app.
3. Estrai lo ZIP e sostituisci devices.json e stock.json nel repository.
4. Copia anche le nuove immagini nella cartella images/.
5. Fai commit/push.

Nota: GitHub Pages è statico. L'app non può scrivere direttamente nel repository; il caricamento dei file resta manuale.
